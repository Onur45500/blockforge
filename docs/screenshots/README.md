## Capture rules

1. Dark UI, real project, no personal paths you would not want public (`C:\Users\...` is usually fine; live keys are not).
2. Export PNG (not JPEG). Width 1600–1920px is enough; GitHub downscales.
3. Do not include Claude transcripts that contain secrets, emails, or unpublished game IPs you do not own.
4. After adding files, preview the README on GitHub (or a local Markdown preview) to check crop and contrast.
