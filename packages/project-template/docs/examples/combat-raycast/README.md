# Server raycast combat (reference only)

Copy `RaycastRack.model.json` into `world/` and `combat-raycast.server.ts` into `src/server/`.

Touch `RaycastRack` → get `RaycastBlaster`. `Activated` raycasts on the **server** from HRP look. Same-team players are skipped. Melee proximity: [tool](../tool/).
