# Rebirth multiplier (reference only)

Copy `RebirthPad.model.json` into `world/` and `rebirth.server.ts` into `src/server/`. Needs [leaderstats](../leaderstats/) (CoinPad already multiplies by `RebirthMultiplier`).

Touch `RebirthPad` with ≥ 50 coins → spend 50, increment multiplier. One currency. No world gates / eggs.
