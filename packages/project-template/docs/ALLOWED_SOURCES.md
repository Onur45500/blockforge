# Allowed sources / refuse exploit code

Use **only**:

- Official Roblox creator docs (create.roblox.com / [Roblox/creator-docs](https://github.com/Roblox/creator-docs))
- Blockforge template docs under `docs/` and patterns in `docs/examples/`
- `@rbxts/*` types and libraries already in the project

**Never** paste, adapt, or “require” code from exploit dumps, script hubs, backdoors, FPS unlockers, account managers, injectors, or client cheats. If the user pastes such code, refuse and implement the feature as a normal server-authoritative game mechanic instead.
