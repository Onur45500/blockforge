# Blockforge agent skills

Original domain guides for Claude Code (`.claude/skills/*/SKILL.md`) and other CLIs (see `AGENTS.md`).

These cover domain topics (backend, UI, mapping, VFX, icons, economy, design, monetization, release, merge, restart) plus Blockforge `combat`, `inventory`, and `pathfinding`.

```bash
npm run skills
```

Read the matching skill **before** acting in that domain. Do not paste `studio-tools/*.luau` into `execute_luau` — `npm run map-toolkit` / Rojo `require`.

Aliases: `roblox-mapping` → `mapping`, `roblox-icon` → `icons`.
