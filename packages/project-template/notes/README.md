# Notes

Persistent game-design memory. Agents must **read** this tree before inventing lore, names, or economy, and **add** a short markdown slice when they ship a system.

```
notes/general/   # pitch, session-zero
notes/design/    # loop, economy, progression
```

Starters in this template: `general/pitch.md`, `general/session-zero.md`, `design/loop.md`, `design/economy.md`, `design/progression.md`.

```bash
npm run notes -- list
npm run notes -- init
```
